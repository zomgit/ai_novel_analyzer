## 🔑 核心配置文件说明

### 1. `config/default.yaml` - 生产默认值

**用途**: 项目的标准配置，确保所有人都能运行

**特点**:
- ✅ 包含所有必需参数
- ✅ 安全默认值
- ✅ 无敏感信息
- ✅ 提交到 Git 版本控制

**何时修改**:
- 调整全局默认行为
- 优化通用参数

---

### 2. `config/production.example.yaml` - 配置模板 ⭐

**用途**: 新手参考模板 + 团队共享配置

**特点**:
- ✅ 详细注释每个参数
- ✅ 列出所有可选值
- ✅ 推荐最佳实践
- ✅ 包含故障排查提示

**如何使用**:
```bash
# 复制为个人配置
cp config/production.example.yaml config/production.yaml

# 编辑配置文件
vim config/production.yaml
```

**关键部分**:
- **AI Model 配置** (行 30-100): AI API Provider、模型选择、超时设置
- **Embedding 配置** (行 105-140): 向量化 Provider、模型、Batch 设置
- **Processing 配置** (行 150-180): 并发数、错误处理、Token 管理
- **Storage 配置** (行 190-220): JSON、向量库、SQLite 路径

---

**内容示例**:

**安全规则**:

- ✅ 定期轮换密钥

**加载方式**:

## 📋 常用配置项速查表

| 配置项 | 位置 | 推荐值 | 说明 |
|--------|------|-------|------|

### 技巧 1: 动态 API 密钥管理

在项目中使用多个团队成员的不同密钥：

```bash
# 使用角色区分
export AI_MODEL_API_KEY_DEV="your-dev-key"

```

代码中按需加载：
```python
import os

env = os.getenv('DEPLOYMENT_ENV', 'dev')
key_var = f'AI_MODEL_API_KEY_{env.upper()}'
api_key = os.getenv(key_var, os.getenv('AI_MODEL_API_KEY'))
```

### 技巧 2: 配置文件继承

主配置文件引用子配置：

```yaml
# config/production.yaml
extends: "default.yaml"  # 继承基础配置

# 仅覆盖必要参数
ai_model:
  params:
    model: "custom-model"

embedding:
  params:
    api_key: "${SILICONFLOW_API_KEY}"
```

### 技巧 3: 环境变量优先策略

优先级顺序：
1. 命令行参数 > 2. `.env` 文件 > 3. YAML 配置 > 4. 代码默认值

```python
# 代码示例
from dotenv import load_dotenv
load_dotenv()

config = {
    'api_key': os.getenv('API_KEY'),  # 优先从 env 读取
} or default_config['api_key']  # 否则用默认值
```

## 🐛 常见配置问题与解决方案

### 问题 1: "API Key not found"

**症状**: `RuntimeError: Environment variable AI_MODEL_API_KEY not set`

**原因**:
- `.env` 文件未创建
- 变量名拼写错误
- 未在代码中加载 `.env`

**解决**:
```bash
# 检查文件是否存在
ls -la .env

# 验证变量内容
cat .env | grep AI_MODEL_API_KEY

# 代码中确保调用了 load_dotenv()
from dotenv import load_dotenv
load_dotenv()
```

---

### 问题 2: "Connection refused to base_url"

**症状**: `requests.exceptions.ConnectionError`

**原因**:
- Base URL 错误
- 服务器未运行（本地服务）
- 网络不通（代理问题）

**解决**:
```yaml
# 检查 base_url
ai_model.params.base_url: "https://api.siliconflow.cn/v1"

# 如果是本地服务，确认端口
http://localhost:1234/v1  # LM Studio
http://localhost:11434    # Ollama
```

---

### 问题 3: "Memory error during batch processing"

**症状**: `MemoryError` 或系统卡顿

**原因**:
- `max_workers` 过高
- 单章文本过长
- 没有启用磁盘缓冲

**解决**:
```yaml
processing.max_workers: 1  # 降低并发
performance.memory_limit_mb: 2048  # 限制内存
performance.disk_buffer_enabled: true  # 启用磁盘缓冲
```

---

### 问题 4: "Model not found in provider"

**症状**: `404 Not Found` 或 `invalid model name`

**原因**:
- 模型名称不正确
- Provider 不支持该模型
- 模型已被下线

**解决**:
查阅官方文档的可用模型列表：
- SiliconFlow: https://siliconflow.cn/models
- OpenAI: https://platform.openai.com/docs/models
- Groq: https://console.groq.com/docs/models

## 🔐 安全最佳实践

### ✅ 应该做的

1. **永远不要硬编码密钥**
   ```python
   # ❌ 错误
   api_key = "sk-xxxxxx"
   
   # ✅ 正确
   api_key = os.getenv('AI_MODEL_API_KEY')
   ```

2. **使用强密码**
   - 至少 32 字符
   - 包含数字、字母、符号
   - 不重复使用

3. **定期轮换密钥**
   ```bash
   # 每季度更换一次
   export AI_MODEL_API_KEY="new-key-here"
   ```

4. **限制访问范围**
   - 只授予必要的 API 权限
   - 设置 IP 白名单（如果支持）
   - 监控使用情况

5. **备份配置**
   ```bash
   git archive --format=tar.gz HEAD > backup-$(date +%Y%m%d).tar.gz
   ```

### ❌ 不应该做的

1. 将 `.env` 上传到 Git
2. 在公开论坛分享密钥
3. 在代码注释中包含密钥
4. 使用简单密码（如 123456）
5. 共享密钥给他人
